# Datasets Description

This repository contains two main datasets containing GitHub project and issue data, formatted as JSON files.

## 1. PDD (Puzzle-Driven Development) Dataset
The PDD dataset is derived from parsing `0pdd` XML files generated by the Puzzle-Driven Development tool. The dataset focuses on "puzzles" (tasks/tickets) embedded directly within source code comments. The issues collected here correspond to these extracted puzzles, enriched with github metadata.

**Location:** `res/pdd_issues_with_stats/`

## 2. General Issues Dataset
The General Issues dataset collects broader issue resolution metrics for standard collaborative GitHub projects. It pulls the most recently closed issues (e.g., from 2023-2024, capped to 400 issues per repo) and tracks repository-level metrics such as language, forks, stars, and contributors without the context of in-code parsed puzzles.

**Location:** `res/general_gh_project_info/`

## Dataset Schema

Both datasets share a common base structure containing standard project and issue information pulled from the GitHub API. 

### Common Schema
```json
{
  "project_link": "String (URL to the GitHub repo)",
  "project_language": "String (Primary programming language)",
  "project_stars": "Integer (Number of Stargazers)",
  "project_forks": "Integer (Number of Forks)",
  "project_contributors_count": "Integer (Number of unique contributors)",
  "issues_count": "Integer (Number of issues fetched)",
  "first_issue_date": "String (ISO 8601 Timestamp of earliest fetched issue)",
  "last_issue_date": "String (ISO 8601 Timestamp of latest fetched issue)",
  "issues": [
    {
      "project_link": "String",
      "issue_link": "String (URL to the specific issue on GitHub)",
      "id": "String/Integer (GitHub Issue/Puzzle ID)",
      "closed_at": "String (ISO 8601 Timestamp) or null",
      "created_at": "String (ISO 8601 Timestamp)",
      "body": "String (Text body of the puzzle/issue)",
      "labels": ["Array of Strings"],
      "assignees": ["Array of Strings (Usernames)"],
      "title": "String (Generated or GitHub issue title)",
      "comments": [
        {
          "author": "String",
          "created_at": "String",
          "updated_at": "String",
          "body": "String",
          "url": "String",
          "id": "Integer"
        }
      ],
      "issue_events": [
        {
          "id": "Integer",
          "node_id": "String",
          "url": "String",
          "actor": {
            "id": "Integer",
            "url": "String",
            "type": "String",
            "site_admin": "Boolean"
          },
          "event": "String (e.g. labeled, referenced, closed, mentioned)",
          "commit_id": "String or null",
          "created_at": "String"
        }
      ],
      "flags": {
        "is_pull_request": "Boolean",
        "is_open": "Boolean",
        "has_assignees": "Boolean",
        "has_labels": "Boolean",
        "has_comments": "Boolean"
      },
      "comments_count": "Integer",
      "issue_events_count": "Integer",
      "time_to_resolution_days": "Float"
    }
  ]
}
```

### Differences Between Datasets

While the datasets share the common structure above, they have a few specific differences at the `issues` level based on how the data was collected:

#### Fields Unique to the PDD Dataset:
Objects in the `issues` array contain the following additional fields related to the puzzle location in the codebase:
- `"ticket"`: `String` (Ticket/issue identifier extracted from the XML)
- `"done"`: `Boolean` (Whether the puzzle was marked done in the XML)
- `"file"`: `String` (Source code file containing the puzzle)
- `"lines"`: `String` (Line numbers of the puzzle in the source file)

#### Fields Unique to the General Issues Dataset:
Objects in the `issues` array contain the following additional metrics:
- `"time_to_resolution_seconds"`: `Integer` (Exact time to resolution in seconds)
