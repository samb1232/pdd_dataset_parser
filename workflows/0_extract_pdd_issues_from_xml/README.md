# Workflow 0: Extract PDD Issues

This workflow handles the initial extraction of puzzle data from the raw XML files generated by the `0pdd` toolkit.

## Scripts
- **`1_parser_xml.rb`**: Scans a directory of XML files (expected at `../../data/0pdd-dataset`), parses each file using REXML, and extracts puzzle-related data into a JSON array. Checks project visibility before including puzzles (via github api).

## Inputs
- XML files located in a data directory (e.g., `data/0pdd-dataset/*.xml`).

## Outputs
- `puzzle_related_data_from_xml.json`: A flat JSON list of extracted puzzles.

## Example Usage
```bash
ruby -I../.. 1_parser_xml.rb
```
